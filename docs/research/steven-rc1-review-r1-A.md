## Checked and fine

- **M3 gate:** `TrailerStartGate.step` matches the spec. Automatic = rest + 1 s. Fixed N = max(focus + N, rest). Ceiling 3 s with no rest. The dwell loop ends in every case: a rest that keeps breaking falls to the ceiling. The default is Automatic (the `@AppStorage` default, and `current()` falls back to it).
- **Rest signals:** `RowRestSource` equality and `isAtRest` are correct. Hero `restSource` is set in `onAppear` and `onChange(of: heroContainerPinned)`, and the loop re-reads it every poll, so `onAppear` ordering cannot matter. Home and Search are the only `CatalogRowView` hosts, and both stamp vertical motion.
- **Playing key:** `playingKeySubject` sends only on change, and a release by a non-owner sends nothing. `onReceive` writes `rowPlayingKey` only when the row's own answer changes. Mute works in both trailer locations (test85B/85C). No other consumer depended on the removed `ObservableObject`; `heroTrailerHolding` is a plain read.
- **R2 state machine:**
  - `morphToken` and `generation` are separate, so a deferred collapse lets the expansion finish.
  - Abort runs in one disables-animations transaction.
  - `collapseInFlight` cannot stick: `beginMorph`, `abortStage`, the completion and the belt Task all clear it.
  - Re-focus during a dissolve keeps the art (token-guarded `finishCollapse`).
  - `onDisappear` aborts.
  - The hero model (`hostsTile == false`) keeps the phase-only path, unchanged.
  - Tasks capture `self` weakly. `dropArtPrefetch` invalidates late art.
- **R1:** the ring table matches `PosterCard`'s rule. `ringWidth` = 4, so the accent ring width is unchanged. The depth overlay draws inside the shape, so the surface clip does not cut it. The colour peek uses the raw URLs, and the store keys on those.
- **B2 listener:**
  - `logListener` never runs with the lock held, and `NSLock` is non-recursive, so this matters.
  - Every waiter is resolved: ready, attempt deadline or exhausted.
  - The rebuild's retire wait is released by `.cancelled` or by the 0.5 s timer, token-guarded so it never runs twice.
  - A stale listener's events are ignored.
  - Same-port retries are bounded.
  - The eager-rebuild budget refills.
  - `.active` verifies before it rebuilds.
  - Observers capture the server weakly.
  - The race is a true one-shot.
  - Detail still calls the legacy `playbackURL(for:)` with no outer timeout (`DetailViewModel.swift:375/434`).
  - DEBUG fault knobs are compiled out of Release.
- **ITC outcome mapping:** `.playable("")` → next candidate, as the old `!isEmpty` checks did. `.timedOut` is never `.unavailable`. `resolvingKey` ownership is preserved on every new branch.
- **M5 text swap:**
  - Every write goes through a fresh animation-free transaction, and only the scoped opacity animates.
  - The `.id` is on the info block, never on the focused CTA.
  - HomeView observes nothing new: the model lives in `HeroTextLayer`, and the DEBUG labels are leaf views.
  - A same-identity sharpen or late backdrop is a silent gap-fill.
- **Cover freeze and logo ink:**
  - A cover cancels only a pending revert, never a pending commit.
  - `cancelAndRevert` clears the uncover task.
  - `HeroPresentation.==` includes `logoInk`.
  - `.blank` commits no bitmap.
  - `.template` tints only `.dark`.
  - Fetched logos are sampled off the main actor before the wait, and the sync sample runs once per URL.
- **M4 row:** shown only while a trailer can start; uses the `descriptionID: .homeTrailerStartDelay` literal form.
- **HomeView body:** the new modifiers are `.environment` constants, `onChange` or `onReceive` actions that write unpublished state, and `.rowsMotionStamp`, which writes a static and no view state.
