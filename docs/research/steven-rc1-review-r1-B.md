## Checked and fine

- **Lookup contract and pools.** Keys are `bucket|identity`, so one URL can sit at two buckets in either pool without collision. `serving` never returns a decode below the request's bucket. `storeBucket` is deterministic per key, so the same key never lands in both pools. Masks fit in a `UInt16` (14 buckets). The lock is never held across an NSCache call. Replacement, eviction and `clearLarge` keep the totals idempotent (`counted` flag plus generation). The `data:` URL identity is short.
- **URL upgrades.** The host match is exact. Only the `/t/p/<size>/` segment is rewritten, and the query string is kept. SVG logos are not rewritten for `.logo` and are excluded from `family`. metahub `background`/`logo` and every other host return nil. `family` is the same file path at other sizes, so no unrelated picture can be served.
- **Failure memo.** It records only non-last candidates and only definitive failures, and it skips only non-last candidates. A URL that is the last (or only) candidate in another chain is always fetched, so no poisoning. TTL 10 min, cleared on profile change.
- **Fetch.** The `.legacy` decode path is byte-identical to before (`min(1920, source)`). `prefetchAndWait` resumes exactly once and never cancels the shared work.
- **Kotlin w780.** Every `posterPath` site uses `TmdbImageSizes.POSTER`. Title logos, entity logos, profiles, backdrops and stills are unchanged. Persisted and synced data (CW, library, TMDB collection covers) now carries w780 URLs, which the phone renders as given. `tmdbImageUrl` now trims the path, which is harmless.
- **F migration.** Only an explicit legacy 3 becomes `off`. An existing `row_edge_fade` (including one from the argument domain) is never overwritten. The legacy key is removed. Nothing registers either key, so `object(forKey:)` cannot be fooled. The DEBUG probe is DEBUG-only. Detail and Episodes rows really sit 140 pt from the bezel (60 pt padding inside the 80 pt safe area), so the standard margins are right.
- **Seed guard.** It imports only when signed out or in an anonymous session, refuses `signedIn`/`authLoading` without latching, and is DEBUG-only.
- **T1.** `TabBarRestFix.leg` is release-safe, read once, and out-of-range values become 0. Leg 0 keeps today's `apply()` order byte-for-byte. Leg 2 is inert at legs 0 and 1 (`isTopSnap` is always false, and the pull-back path is unchanged). The relink task is cancelled on window exit, teardown and deinit. `off=`/`ins=` clamp in floating point, and `homeRowsScrollView` is cleared when Home unlinks.
- **A.** The sort is stable (`sortedWith`) and ties keep list order. Binge-group, regex, manual and binge-only paths are unchanged. Mobile keeps `LIST_ORDER` (only `installTvOsSharedProviders` sets BEST). Every Swift caller passes `ranking:`, and the forced first-stream mode (manual plus next-episode toggles) keeps list order. The preparer prepares the link that auto-play picks.
- **D1.** All seven action-button keys exist with fr/de/es/it/vi translations, and `String(localized: LocalizedStringResource)` resolves against the main bundle. `actionLabel(verbatim:)` keeps Kotlin's already-localized caption. The `Group` around the series Play label sits inside the Button label, so it adds no focus identity.
- **D2.** Only `isTrailerActive` and the A/B legs flatten now, the chips and the panel share one rule, and `debug_ux6 glass=` reads the same rule. This drops a BUG-41 scroll mitigation; that was Christian's call, and the device pass has `[BUG41] hitches=` for it.
- **D3, P.** The constants match the spec tables. The DV detection reads the locked `videoSignaling` and assigns only on change.
- **C.** The geometry is consistent: `Bf − Bc = R` for any chip height, and the chips' layout frame equals their drawn frame for s ≤ R. The visualEffects write no state. The reveal gate re-arms on a tab change and survives push and pop. The ghost chip row is hidden and disabled, so it cannot take focus. Edit Filters stays the BUG-47 anchor when the grid is empty.
- **Tests.** `ArtworkMemoryTests`, `ImageFallbackPlanTests`, `RowEdgeFadeSettingTests`, `PinnedRowTopSnapTests`, `TabBarContentScrollLinkTests`, `DetailAboutRowsTests`, `NativePreparingLabelTests` and `StreamAutoPlayBestQualityTest` all exercise real branches. test70 now compares the same card in the same state and fails loudly when a region holds no artwork.
